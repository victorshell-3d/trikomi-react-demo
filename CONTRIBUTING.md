# Contributing to Trikomi 3D Platform Showcase

Thank you for your interest in contributing to the **Trikomi 3D Platform** public showcase! We welcome contributions from developers, 3D artists, UI designers, and open-source enthusiasts worldwide.

---

## 🌟 How Developer Enthusiasts Can Contribute

### 1. UI Polish & Component Enhancements
- Refine responsive mobile views for customizers (`sportswear-configurator`, `jewelry-configurator`, `box-configurator`, `eyewear-tryon`).
- Implement smooth glassmorphic UI controls, micro-animations, or dark/light mode toggles.

### 2. Bug Reports & Testing
- Test WebGPU / WebGL rendering across different GPUs, Android devices, iOS Safari, and desktop browsers.
- Submit detailed GitHub Issues with console logs or screenshots.

### 3. New Theme Templates & E-Commerce Integration References
- Add new sample 3D models or UI presets for customizers.
- Submit example integration scripts for Shopify Liquid, WooCommerce PHP, or Next.js.

---

## 🛠️ Contribution Workflow

1. **Fork the Repository**: Create your personal fork on GitHub.
2. **Clone & Install**:
   ```bash
   git clone https://github.com/your-username/trikomi-demo-react.git
   cd trikomi-demo-react
   pnpm install
   ```
3. **Create a Feature Branch**:
   ```bash
   git checkout -b feature/ui-polish-sportswear
   ```
4. **Make & Verify Your Changes**:
   ```bash
   pnpm dev
   ```
5. **Submit a Pull Request (PR)**: Open a PR against the `main` branch with a clear summary of your improvements.

---

## 🏅 Contributor Recognition

Contributors who have Pull Requests merged will be recognized as **Official Contributors** and featured on our partner page at [victorshell.com/partners](https://victorshell.com/partners).

For questions or developer discussions, reach out to **support@victorshell.com**.
