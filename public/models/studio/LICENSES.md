# Studio collection assets

The following unmodified assets are copied from the existing jewelry studio collection. They are stylized visual assets, not manufacturing geometry. Runtime orientation and the app's existing model loader determine their display.

- pendant.glb: https://grab3d.com/models/props/pendant/
- necklace.glb: https://grab3d.com/models/props/necklace/
- bracelet.glb: https://grab3d.com/models/props/bracelet/

These files do not replace the existing upstream ring models. No Earrings asset is included.
